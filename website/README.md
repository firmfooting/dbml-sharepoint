# dbml-sharepoint documentation site

Docusaurus 3, docs-only mode. The docs tree is the site.

```bash
npm install
npm start          # local dev server
npm run build      # static build into build/
```

`docs/api/` is **generated** — do not edit those pages by hand:

```bash
uv run python scripts/generate_api.py   # from the repository root, or:
npm run generate-api                    # same thing, from website/
```

Everything else under `docs/` is hand-authored. Ordering comes from
`sidebar_position` frontmatter and `_category_.json` files; the sidebar
itself is autogenerated from the tree (`sidebars.js`).
